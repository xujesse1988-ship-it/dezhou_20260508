## 0. 要点

1. **数据来自 all-1pot，不是 flop2-1pot** [事实]：run4 / run5 的 play.log 都是 `ready reshape=all-1pot ... update_count=8000000000`。两者翻前树逐节点相同（`reshape_flop2_1pot_only_flop_widened` 单测保证），但是分开训练的，**策略数字要在 flop2-1pot 上重新核对**。
2. **先开池基本正常，少的是面对加注的防守** [事实]：先开池只有 HJ 偏紧（16% 对参考 ~21%）；BB 防 CO / HJ 开池只有 14% / 11%，SB、BTN、CO 面对开池只入局 0–8%。
3. **两个原因** [事实 + 推断]：
   - 尺寸对不上：对手 87% 的开池 ≤ 3BB，树里开池只有 1pot（3.5BB）一档，比最小档还小的加注直接对应到最小档（`map_off_tree` 的 clamp 分支），blueprint 是按「面对 3.5BB」在防守。
   - 对手开得更宽：牌池先开池加注率 HJ 29%、CO 34%，blueprint 自己 HJ 只开 16%，它以为对手也这么紧。
4. **全部补到参考值，入局率约 +3.5 个百分点**（21.5% → 约 25%）[推断]，其中 BB 防开池约占 44%。
5. **翻后的主要风险是「我方走到范围外的线」** [事实，代码确认]：搜索估我方范围用 blueprint 的翻前策略，且我方不混均匀分布。翻前多跟进来的牌在范围里权重接近 0。10-17 调研已经量到：我方线在范围外时，弱牌全下概率翻倍（0.119 对 0.055）。**不先修这一点，放宽翻前只会把亏损搬到翻后。**
6. **建议**：加哪些牌由离线模拟的**整手 EV** 决定，不用底池赔率比例；同时让搜索看到放宽后的我方范围；再用带搜索的完整流程做「同一副牌两遍」对照；三项都过才上线。

## 2. 翻后会怎么处理新加进来的牌（代码核查）

### 2.1 各街走哪条路 [事实]

- 翻牌：过了码深门和尺寸门走 blueprint，否则走搜索。走 blueprint 时按手牌所在的桶查策略，**不依赖我方范围**，新加的牌没有额外问题。
- 转牌 / 河牌：crop 只留到翻牌，一律走搜索。

### 2.2 搜索里我方范围的问题 [事实 + 推断]

- `subgame.rs` 估各座范围用 `estimate_range`（沿实际路径乘 blueprint σ），对手再按 `range_uniform_mix` 混入均匀分布；**我方不混**（`mix_lambda_for_seat` 对 hero 返回 0）。[事实]
- 搜索按范围权重给各家发牌（`sample_holes_from_ranges`），策略按桶记。翻前 blueprint 几乎必弃的牌，在我方范围里权重接近 0 → 几乎不被抽到。[事实]
- 同一个桶里还有范围内的其他牌，所以多数情况不会直接放弃；但这个桶的平均策略可能只训练了很少几次。`read_current_strategy` 只拦「完全没学到 / 恰好均匀」两种情况，**没有访问次数下限**。[事实]
- 求解器以为我方范围仍然很紧、很强 → 解里的对手面对我方下注弃得更多 → 我方弱牌诈唬偏多。[推断]
- 10-17 调研的实盘证据：我方线在范围外（前面有 limp 启发式 / 兜底 / 抽中 < 10% 的动作）时，弱牌全下概率均值 0.119，正常线 0.055；11 手弱牌全下里 6 手属于这种情况。[事实，见 `openpoker_postflop_weak_allin_research_2026_10_17.md` §0 第 3 条、§3.1]
- 整个桶都在范围外时，搜索放弃 → `fallback_with_floor`：能过就过，否则弃（另有坚果跟注、底池赔率两道地板）。[事实]
- 本次数据：翻前以 5–20% 概率跟进的 6 手，翻后 15 次决策没有出现放弃。样本太小，说明不了问题。[事实]

**结论**：放宽翻前 = 主动制造「范围外的线」。它会同时触发两类翻后问题：被放弃后弃掉，或者打得过激、输更多。所以翻后一致性必须和翻前放宽**一起做**，而且依赖 10-17 文档 §5 第 1、2 条（访问量诊断和访问量门槛）。

## 3. 方案

### 3.1 用整手 EV 决定加哪些牌（离线模拟）

先只做 **BB 防单人开池**：之前无人平跟，只有一次开池，BB 后面没人，局面最干净，而且占可增量的大头。

- 局面：某位置开 s BB（s = 2.25 / 2.5 / 3），其他人弃到 BB。
- 对 169 种起手牌，强制 BB 跟注，之后所有人的所有决策都按 blueprint 打到底（需要完整 checkpoint，因为要用转牌和河牌策略），统计 BB 的平均净输赢 EV_call(h, 开池位置, s)。
- 弃牌的结果固定为 −1BB（大盲已投入）。**加入条件：EV_call > −1BB + 余量**（余量先取 0.1BB，用来盖住模拟和实盘打法的差别）。
- 翻后被打掉、输更多的代价都已经包含在 EV 里，这正是本方案要回答的问题。
- 实现：基于 `blueprint_advisor::evaluate_cross_abstraction_h2h` 的「一张真实牌局 + 每个 blueprint 各自按树对应局面」框架。2.5BB 开池会经 `advance_shadow_by_applied` 自动对应到 1pot 节点。需要新加的是：固定翻前前缀 + 强制 BB 动作 + 按手型分桶统计。
- 已加入 3bet 的牌和频率保持 blueprint 不变，新加的牌只跟注。

局限：

- 模拟里翻后全用 blueprint；实盘转牌 / 河牌走搜索，翻牌部分走搜索。结果只是近似，要靠 §3.3 补。[推断]
- 对手按 blueprint 的开池范围开，比牌池紧（§1.3），这会让 EV 估低，结论偏保守。[推断]
- 对手翻后也是 blueprint，不是真实牌池。

### 3.2 翻后一致性：搜索看到放宽后的我方范围

- 估我方范围时，在被放宽的那个翻前节点上，用**放宽后的翻前策略**代替 blueprint σ（包一层 strategy 闭包：节点 = 该翻前节点且座位 = 我方 → 返回放宽后的分布）。跨街后验从上一街的解来，上一街已经用对的范围，就自然一致。
- 对手范围不动。
- 放宽规则（哪些位置 / 尺寸 / 手型改成跟注）放在 `src/training` 的库代码里，advisor 和离线工具共用一份，避免测的和上线的不是同一套逻辑。
- 前置：10-17 文档 §5 第 1 条（记录我方 infoset 的访问次数）先做。用它确认放宽之后，新加的牌在搜索里确实被充分访问。

### 3.3 用带搜索的完整流程验证（同一副牌两遍）

- 同一副牌、同一 seed 跑两遍：A = 原策略（弃牌），B = 新规则（跟注）。翻前没改动的手两遍完全一样，**只需要对改了动作的手跑完整流程**（约占全部手数的 3%），成本可控。
- 我方用完整 advisor 流程（含搜索、尺寸门、码深门），对手用 blueprint。
- 看三个数：
  1. 新加的手平均净输赢是否 > −1BB（带 CI）；
  2. 这些手翻后被搜索放弃的比例；
  3. 这些手翻牌面对下注的弃牌率，以及弱牌全下率（对照 10-17 的 0.055 / 0.119）。
- 三项都过才上线。

### 3.4 实盘护栏

- 新加的跟注单独打标签（如 `source=preflop_widen`），翻后决策带上「本手翻前是放宽进来的」标记。
- 每批（约 500 手，按 `openpoker_batch_review_framework.md`）单独统计：这些手的翻后放弃率、弱牌全下率、全下 EV 口径的净输赢（对照 −1BB）。

### 3.5 推广顺序

1. BB 防单人开池（本文档主体）。
2. SB / BTN / CO 防单人开池：后面还有人，要处理被挤压（squeeze）和多人池，模拟时让后面的人也按 blueprint 行动即可。
3. HJ 先开池偏紧（+0.6 个百分点）：可能只是训练噪声，优先级最低。

### 3.6 预期

- 入局率涨多少由 §3.1 的模拟结果决定，可能明显低于 +3.5 个百分点。
- 如果模拟显示多数新加的牌跟注都不如弃牌，说明 blueprint 现在的防守宽度在它自己的翻后打法下是对的。那么该改的是翻后打法（OOP 只有 1pot 下注档、实现率低），而不是翻前。

## 4. 不建议的做法

| 做法 | 为什么不做 |
|---|---|
| 按底池赔率比例放宽（如 3.5BB 和 2.5BB 下所需胜率之比） | 不看翻后能不能打得动，正是「翻前入局多了、翻后弃掉或输更多」的来源 |
| 调抽样（如去掉低概率弃牌） | 边缘牌在 blueprint 里基本是 100% 弃，抽样动不到它们 |
| 改座位映射 | 短桌把前面的空位当作已弃牌，与真实短桌等价 |
| 翻前实时搜索 | 方向最正，但 9 座翻前子树要接翻后续局值，工程量远大于本方案 |

## 5. 附：重训方案的评估（同日讨论）

用户最初提的三种重训方案：

| 方案 | 结论 | 理由 |
|---|---|---|
| 翻前加 0.5pot 加注 | 方向对，但成本高 | 直接对上对手的小尺寸开池；树大一倍多（见下表） |
| 100BB 改 50BB | 不建议 | 实盘开局栈中位数 100BB，按 50BB 训练是为另一种码深练策略；浅码平跟隐含赔率更差，未必更宽 |
| 加 ante | 不建议 | 实盘没有 ante；加了入局率一定升，但是按不存在的底池算赔率，会松得亏钱 |

翻前改 {0.5, 1}pot 后的节点数（9 座、100BB、cap4、500 桶，两表每格 8 字节；现有 run 的 5,142,747 节点 / 78.52 GiB 与训练日志一致，验证了计算方法）[事实]：

| | 翻前 | 翻牌 | 转牌 | 河牌 | 总节点 | 两表 | 裁到翻牌 |
|---|---|---|---|---|---|---|---|
| flop2-1pot（现状） | 179,363 | 650,184 | 1,589,580 | 2,723,620 | 5,142,747 | 78.52 GiB | 11.59 GiB |
| 翻前 {0.5,1} 两档开池 | 373,649（+108%） | 1,518,452（+134%） | 3,728,802 | 6,294,626 | 11,915,529 | 183.30 GiB | 27.12 GiB |
