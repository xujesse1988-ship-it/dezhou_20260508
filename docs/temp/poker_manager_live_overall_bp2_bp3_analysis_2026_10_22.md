## 0. 结论

1. **数据全部可信**：11 个目录重新流式核对，零和、串链、请求栈、`dealt_seats`、hh 和 ws 一致性全部 100%。
   缺结果的手都是叫停 / 中断时正在打的那一手。[事实]
2. **总战绩：+1776.6 BB / 15280 手 = +11.6 ± 8.3 bb/100**，全下折算 +8.2。去掉早期没有码深离场、码深打到 800 BB 的 105159 那批，
   14280 手 **+7.5 ± 8.5 bb/100**（折算 +4.6）。方向是正的，但离显著还差得远。[事实]
3. **bp3 +25.7 bb/100（7000 手），bp2 −10.0 bb/100（同期 7280 手）**，差 36 bb/100，约 2 个标准误。
   查下来**不是打法差异**：同一套代码，翻前翻后统计几乎一样，打法可疑的手两边各占一半；
   差距集中在摊牌的大底池，尤其是「翻牌时已经大幅落后、钱还是进去了」的冷遇（bp2 31 手 −1700 BB，bp3 25 手 −539 BB）。
   按对手拆，差距来自 claudeh（bp2 对他 −459，bp3 对他 +816）和两个账号互相之间（约 230 BB 流向 bp3）。[事实 + 推断]
4. **全场最大赢家是 cc（3953 手 +107 bb/100），他赢钱的方式正是我方最大的漏洞**：我方开局被 cc 3bet 后弃 53%（206/390，合计 −747 BB），
   而 cc 被 4bet 后弃 96.5%（139/144，[92%, 98.5%]）。大盲面对 cc 开局弃 88%。
   我方和 cc 之间：≥ 40 BB 的大底池 +1556 BB，其余小底池 −1696 BB。翻后打 cc 是赢的，钱漏在翻前。[事实]
5. **重看 45 手大输**：36 手 A（冷遇 / 合理），8 手 B（打法可疑，合计 −786 BB），1 手 D（兜底路径）。
   B 类集中在两种情况：翻前加注大战里中等牌全下（KTs、66、QTs），和访问量刚过门槛的搜索给出极端动作（JJ 全下 .85 访问量 295、TT 跟全下 1.0 访问量 206）。
   和之前各批的分类相比，改判了 3 手（§6.3）。[事实 + 推断]
6. **跨批反复出现、值得动手的问题按收益排序**：
   ① 翻前面对高频 3bet 对手的 4bet / 跟注规则（PM-17，证据最硬、收益最大）；
   ② 放弃搜索后的兜底规则：26 次弃牌里有 KK、AQs 顶两对这类该跟的牌（PM-9）；
   ③ 翻前加注大战中等牌全下（B9 家族）；
   ④ 剥削模块基本没生效（PM-18）。翻后面对小注弃牌偏多的问题样本仍然太小，先不动。

## 3. bp2 和 bp3 为什么差这么多

同一套代码、大部分时间同一张桌，bp3 +25.7、bp2 −10.0（去掉 105159），差 36 bb/100，差值标准误约 17。
差这么多的可能原因逐条看：

### 3.1 打法统计几乎一样 [事实]

| 统计（去掉 105159） | bp2 | bp3 |
|---|---|---|
| VPIP / PFR | 14.3% / 10.4% | 16.5% / 12.2% |
| 无人入池时开局 | 16.4% | 18.3% |
| 面对一个开局：跟 / 3bet / 弃 | 6.7% / 5.0% / 88.3% | 6.9% / 5.6% / 87.5% |
| 开局后被 3bet：弃 | 51.0%（106/208） | 54.6%（154/282） |
| 看到翻牌 / WTSD / W$SD | 7.8% / 21.3% / 62.8% | 8.7% / 21.8% / 66.9% |
| 小盲 / 大盲面对单个开局弃 | 90% / 83% | 91% / 82% |

两边的差别在一两个百分点，和桌上人数、座位分布不同有关 [推测]。之前各批都核对过，实际频率和 `probs` 算出来的期望一致，
所以两边执行的是同一个策略。

### 3.2 打法可疑的手两边差不多 [事实 + 推断]

§6 重看的 45 手里，B 类 bp2 5 手（−483 BB）、bp3 3 手（−303 BB），另外 bp3 有 1 手 D 类（−81 BB）。差几百 BB，解释不了 2500 BB 的差距。

### 3.3 差距在摊牌的大底池里 [事实]

| | bp2 | bp3 |
|---|---|---|
| 摊牌手合计 | +869 BB（121 手） | +2699 BB（133 手） |
| 不摊牌手合计 | −1140 BB | −772 BB |
| ≥ 50 BB 的手 | 70 手 +399 | 68 手 +2555 |
| 其余的手 | −1126 | −754 |

把两人摊牌的手（bp2 133 手、bp3 138 手）按「对手亮出来的牌」逐街拆开（`luck2.py`）：

| 翻牌时我方对亮牌的胜率 | bp2 手数 / 合计 | bp3 手数 / 合计 |
|---|---|---|
| < 20%（已经大幅落后） | 31 / **−1700 BB** | 25 / −539 BB |
| 20–50% | 22 / −324 | 19 / −249 |
| 50–80% | 33 / +733 | 41 / +697 |
| ≥ 80%（大幅领先） | 47 / +1700 | 53 / **+2805** |

翻牌、转牌、河牌发牌本身带来的运气（每张牌前后胜率变化 × 当时底池）bp2 +176 BB、bp3 +607 BB，只解释了约 430 BB 的差距。
剩下的差距在「翻牌时谁领先」这一档：bp2 落后时平均每手输 55 BB，bp3 平均输 22 BB；bp2 领先时平均每手赢 36 BB，bp3 赢 53 BB。

bp2 落后那一档里输得最多的几手（§6 逐手看过）：AA 撞 TT 暗三（−158）、JJ 撞 AK（−153，B）、88 撞 AA（−156）、AA 撞 55 葫芦（−112）、
QQ 撞 55 暗三（−55）、44 葫芦撞 KJ 大葫芦（−107）、66 在 Q99 全下撞 AQ（−102，B10）、TT 跟全下撞 AQ（−87，B6）。
大部分是 100 BB 码深下正常会全进去的冷遇，少数是 B 类。[事实]

需要说明：这个拆法只能用在摊牌手上（要知道对手的牌），而能走到摊牌本身就和牌面有关，所以只能当参考，不能当成 AIVAT 那样的无偏估计。[推断]

### 3.4 其他可能的结构差异 [事实 + 推测]

- **对手**：bp2 对 claudeh −459 BB，bp3 对 claudeh +816 BB。claudeh 是全场最大输家（−80.8 bb/100），bp2 没赢到他的钱。
  bp2 对 claudeh 的 13 手大底池（|流向| ≥ 40 BB）合计 −371，其中 AA 撞 55 葫芦、66 暗三撞河牌同花、44 葫芦撞大葫芦、AK 撞 A9 三条，都是冷遇。
- **两个账号互相之间**：bp2 → bp3 约 230 BB，主要是 QQ 对 KK、99 对 AA（河牌 A）、77 对 JT、QQ 对 AKs 四手，合计约 −388 BB；反过来 AA 对 AK 一手 +127。
  座位上 bp3 大多坐在 bp2 左手边（112614 有 1653 手 bp3 的右手是 bp2；151233 有 1246 手 bp2 的左手是 bp3），bp3 在两人对局里多数时候有位置。
- **机器**：bp2 的 162549 / 203354 / 002708 在 Mac 上跑（2855 手 −16.3 bb/100），翻后搜索迭代数第 10 百分位只有 60–74 万（AWS 是 100 万），
  中位数相同，hero 访问量分布也差不多。影响应该很小。[推断]
- **剥削开关**：bp2 151233 / 113600 开了 `--exploit on`，但上一批已查明画像几乎没用到 cc 身上（PM-18），这两批实际按均衡在打。

**结论**：没有找到 bp2 打得比 bp3 差的证据。差距约 2 个标准误，集中在几十个大底池的冷遇上，按现有数据应当看成运气。
两个账号代码相同，以后看赢率只看两边合计。[推断]
