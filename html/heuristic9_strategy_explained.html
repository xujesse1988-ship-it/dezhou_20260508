1. 它是什么

市面上最强的扑克 AI(比如 Pluribus)靠海量算力"求解"博弈,算出一张巨大的策略表——强,但像黑盒:没人能说清它为什么在某一手选择加注。Heuristic9 走的是另一条路:把职业玩家的打牌逻辑写成一套明确的规则。每一个决策都能回答"为什么"——因为胜率够、因为对手太紧、因为赔率划算。

三个关键词:

  • 分层 —— 先算胜率,再看局面性质,再按场景规则出牌,最后针对具体对手微调;
  • 可解释 —— 每个决策都留有"痕迹":当时胜率多少、过了哪条门槛、掷了什么骰子;
  • 人数无关 —— 同一套规则从单挑打到 9 人桌,不用重新训练。

2. 每个决策怎么做出来:六步流水线

轮到它行动时(无论翻牌前后),它都走同一条流水线:

1看清牌桌重建当前局面:底池、各家筹码、行动历史、公共牌
→
2猜对手的牌根据每个对手这手牌的一路动作,推测他的手牌范围
→
3算胜率蒙特卡洛模拟上千次发牌,算出对上这些范围的真实胜率
→
4场景规则命中一个具体场景节点(如"翻牌·单加注池·无人下注"),按该节点的规则选动作
→
5针对性微调按对手档案(紧/松/疯)调整价值门槛、诈唬频率、下注尺寸
→
6合法性检查保证输出动作合法;万一出错,保守兜底(能过牌就过牌)

整条流水线的核心思想:把所有信息折算成一个数——胜率,再用场景规则决定"这个胜率值不值得投钱"。

3. 通用货币:胜率(equity)

胜率(equity)是整个引擎的地基:"如果现在把牌发完摊牌,我平均能赢下底池的百分之几"。它不查表打分,而是真的模拟:给每个对手从他的"可能手牌范围"里发一手牌,补完剩下的公共牌,摊牌比大小——重复上千次,统计赢的比例。

翻牌前还有一把随时可用的尺子:169 种起手牌强度表。德州所有起手牌按"对子 / 同花 / 不同花"归成 169 类,启动时给每一类跑一遍"对一个随机对手"的模拟,得到 0 到 1 的强度值。随机两张牌约等于 0.5,越强越接近 1:

起手牌强度尺(对一名随机对手的胜率)

翻牌前所有门槛(开池、3bet、全下)都用这把尺子;后文出现的 0.505、0.585 之类的数,单位都是它。s = 同花(suited),o = 不同花(offsuit)。

为什么这招能"人数无关"? 因为模拟时每个还在场的对手各自有一条手牌范围,各发各的牌。三个对手就同时对三条范围摊牌——胜率自动变低,多人局"该收紧"不用另写规则,它从数学里自己长出来。

4. 读人:猜对手拿什么牌

算胜率之前必须回答:对手可能拿着什么牌?这是全引擎最关键的一环——范围猜得准,后面所有门槛才有意义。基本思路是"听其言,观其行":一个人这手牌做过什么动作,就暴露了他的牌力下限。

这只是起点。范围还会随三件事继续收紧或放宽:

  • 街越晚越紧:翻牌 +0.03、转牌 +0.06、河牌 +0.09——到了后面的街还愿意投钱,牌就越诚实;
  • 注越大越紧:本条街的下注者,下注占底池比例越高,越假设他有真牌(最多 +0.18)。这是刻意针对弱场的假设——普通玩家"下大注 = 有货",职业场未必如此;
  • 看人下菜:观察满 18 手后,紧手(nit)的下注范围再收紧 0.12,跟注站放宽 0.12(见第 8 节)。
举个例子。对手在按钮位开池加注(范围≈前 17%),你在大盲跟注。翻牌 A♠7♦2♣,他又下注一半底池。此时他的范围 ≈ 0.17 档起点 + 翻牌收紧 + 下注收紧——比他翻前开池时还紧。所以你拿个中对,引擎会算出胜率不够,直接弃掉。这正是老玩家说的"干燥 A 高面上别跟持续下注"——但这里不是背口诀,是从范围推出来的。

进阶:实战默认用的是机器学习版范围。上面的"百分比截断"是保底模型——它把范围压成"从最强往下取到某条线"。实战里默认跑一个小型神经网络(GRU),吃进对手的整串动作序列,输出 169 类手牌的完整概率分布——能表达"他这条线更像听牌/诈唬"这类截断模型说不出的形状。两条路输出口径相同,神经网络产物缺失时自动退回保底模型。

5. 翻牌前怎么打

位置:不数座位,数"还有几个人没行动"

翻前策略核心是位置 × 牌力门槛。它不用固定的"枪口位/中位/CO/按钮"叫法,而是把座位换算成"相对按钮还剩几人"的桶:前位 / 中位 / 后位 / 小盲 / 大盲——这样 6 人桌和 9 人桌能共用同一套规则。位置越靠后,越晚行动信息越多,开池门槛越低:

翻前的完整决策顺序

前面没人加注时

  1. 短筹码覆盖层:有效筹码 < 25bb 且强度 ≥ 0.60 → 直接全下
    短筹码没有翻后周旋空间,推/弃是数学最优的简化
  2. 强度过位置门槛(见上图)→ 开池加注 2.3bb,每有一个 limper 再加 1bb(把跟风者隔离出去)
  3. 投机跟注:强度 ≥ 0.51、跟注 ≤ 1.5bb、前面已有人入池 → 便宜跟注
    小对子、同花连张:博翻牌中暗三/强听牌,靠"隐含赔率"回本
  4. 其余:大盲能免费看就过牌,否则弃牌

面对加注时

  1. 短筹码覆盖层:同左,强度够就全下
  2. 价值再加注:面对开池,强度 ≥ 0.64 → 3bet;面对 3bet,强度 ≥ 0.70 → 4bet
    尺寸:有位置 ×3 倍,没位置 ×4 倍(没位置要把底池打大补偿劣势)
  3. 赔率跟注:用真实胜率对比底池赔率,划算就跟注
    深筹码(>40bb)时投机牌额外给一点"隐含赔率"折让;面对的加注级别越高,折让越小(容易被更大的牌"支配")
  4. 都不满足:弃牌
一个专门修过的坑:大盲防守。早期版本大盲拿边缘牌面对小加注也弃,长期被偷盲打穿。现在只要底池赔率划算就防守,不再硬卡牌力门槛——这条改动就是靠"分场景记账发现大盲位置持续漏钱"定位出来的(见第 10 节)。

6. 翻牌后怎么打

翻牌一发,除了算胜率,引擎还提取三个互相独立的信号——它们的作用是区分"胜率相同但性质完全不同"的牌:同样 50% 胜率,可能是中对(该控池),也可能是同花听牌(该半诈唬),打法天差地别。

信号一:成手档位

空气 Air没成对、没像样听牌 —— 只能诈唬或放弃
弱对底对、低于牌面的口袋对
中对第二大的对子 —— 价值下注的最低门槛
顶对/超对顶对或口袋超对 —— 可以打大底池
强牌两对、三条
怪物 Monster顺子及以上 —— 考虑超额下注榨取

信号二:听牌

"值得半诈唬"的听牌 = 同花听牌、两头顺听牌、或复合听牌(两者兼具)。只有卡顺(4 张补 1 张)不算——出牌概率太低,撑不起半诈唬的数学。

信号三:牌面湿度

干燥牌面
A♠
7♦
2♣

三色、不连张——谁都很难有听牌。诈唬频率高(空气 c-bet 约 80%),下注小(约 1/3 底池)就够赶人走。

潮湿牌面
9♥
8♥
7♠

两同花、三连张——满地听牌。诈唬频率降(约 55%),但真下注就下大(约 0.8 底池),不给听牌便宜看牌。

引擎把"是否成对 / 两同花 / 单色 / 连张程度"综合成一个 0–1 的湿度值,诈唬频率和下注尺寸都随它连续滑动。

翻后的两张决策阶梯

翻后所有决策归成两种局面,各自一条"从上往下,第一个满足就执行"的优先级阶梯:

没人下注(我可以下注或过牌)

  1. 价值下注:胜率 ≥ 0.58 且成手 ≥ 中对 → 下注要钱
    有位置单挑放宽到 0.53(敢打更薄);每多一个对手 +0.03(多人收紧)
  2. 低 SPR 承诺:底池已大(SPR < 2.5)且拿顶对以上 → 下注,准备全下
  3. 半诈唬:有像样听牌且胜率 ≥ 0.28 → 75% 的频率下注
    两条路赢:对手直接弃,或跟注后自己听中
  4. 空气 c-bet(我是进攻方):按频率继续开火诈唬(频率见下图)
  5. 空气偷池(我不是进攻方):极低频率试探性下注(float,基础仅 15%,且被对手档案严格门控)
  6. 其余:过牌(控池或放弃)

面对下注(弃牌 / 跟注 / 加注三选一)

  1. 价值加注:胜率 ≥ 0.64 且顶对以上 → 加注
  2. 强听半诈唬加注:复合听牌(如同花听+顺听)→ 约 50% 频率加注,多人时减半
  3. 赔率跟注:胜率 ≥ 底池赔率 + 0.02 的安全边际 → 跟注
    非河牌的听牌享受隐含赔率折让(筹码越深折让越多,最多 0.12)
  4. 纯诈唬加注:空气、非河牌 → 加注,但基础频率仅 0.6%,几乎不做
    只有当统计确认这个对手"被加注就弃"(弃牌率>30%)才逐步升频,上限 40%(第 8 节)
  5. 都不满足:弃牌——绝不做胜率不够的跟注

7. 下多大注

下注尺寸(以底池的倍数计)

在此基础上:SPR < 2(底池相对筹码很大)再 +0.15 池,为全下做铺垫;价值注还有专属放大器——确认对面是跟注站 ×1.3,单加注池对任何有档案的对手 ×1.5(上限 1.6 池)。诈唬永远不放大:把诈唬下大,只会对不弃牌的人多送钱。

8. 剥削:给对手建档案

前面的规则对"平均对手"就能赢,但弱场里最大的利润来自针对具体的人。引擎跨牌局、跨场次给每个对手记三个经典指标:

  • VPIP —— 主动投钱入池的手数占比(松紧度);
  • PFR —— 翻前加注占比(主动性);
  • AF —— 翻后(下注+加注)÷ 跟注(激进度)。

观察满 18 手后分类,并翻译成具体调整:

📞 跟注站

VPIP > 45% 且翻后不激进(AF < 1.5)
  • 价值下注门槛降 0.12——敢用更薄的牌要钱
  • 诈唬频率 ×0.5——他不弃牌,诈唬就是烧钱
  • 价值注尺寸 ×1.3——他跟得起大注,就下大点多榨

🪨 紧手(Nit)

VPIP < 16%
  • 他下注 = 有真货:把他的范围再收紧 0.12,该弃就弃
  • 全桌都是紧手时:开池门槛降 0.12 多偷盲,诈唬 ×1.3

🔥 疯子(Maniac)

AF > 3.5,或 VPIP > 40% 且 PFR > 30%
  • 他的下注掺水多:范围放宽读,用更弱的牌抓诈
  • 价值门槛降一点(0.048),自己少主动诈唬(×0.8)——让他替你把钱打进底池

🎭 松凶(LAG)

VPIP > 30% 且 VPIP−PFR > 18%
  • 范围读法略放宽(0.048),其余按常规打

⚖️ 紧凶(TAG)/ 未知

其余,或观察不足 18 手
  • 不做任何调整——按"平均对手"的默认策略打

更细一层:分场景记账的"门控"

光知道一个人"总体紧不紧"还不够。引擎给每个对手按场景分格记账:比如"翻牌·单加注池·面对持续下注"这个格子里,他弃牌率究竟多少。攒够 30 次观察后,这个数字直接驱动对应场景的诈唬频率——弃牌率高就多打他,粘就彻底停手:

对手在该场景的弃牌率 → 我的诈唬频率乘数

空气 c-bet 门
看:他面对持续下注弃不弃(仅单加注池)

只降不升:粘人降到 ×0.15,爱弃的保持默认(默认已经够高)。没数据时 ×1。

float 偷池门
看:他被试探性下注打弃不弃

双向:弃牌率<50% 的人完全不偷(乘 0),明确爱弃的可以放大到 ×3。没数据时 ×0.5。

诈唬加注门
看:他下注后被加注时弃不弃

对"被加注就跑"的人最高 ×2;对粘人乘 0 彻底止损。没数据时基础频率仅 0.6%,几乎不做。

三个门共用同一套机制:统计弃牌率(小样本先向全场平均值收缩,避免三五手就妄下结论)→ 在两个锚点间线性映射成频率乘数。锚点数值全部由数千手的靶场模拟校准,不是拍脑袋。

9. 安全网与"受控随机"

  • 合法性地板:任何决策最后都过一道检查——动作必须在规则允许的集合里,加注额夹进最小/最大范围。实测 20,000 手 0 次非法输出。
  • 异常兜底:万一内部出错(比如收不到手牌信息),能过牌就过牌,不能就弃牌——绝不崩溃、绝不乱打。
  • 受控随机:"80% 频率 c-bet"这类掷骰子,用的是由当前局面(手牌+公共牌+底池)派生种子的伪随机数。好处有两个:同一局面回放必然得到同一决策(可复现、可调试);而种子随局面变化,对手看不出"它每次都在同类局面做同样的事"的规律。

10. 它怎么变强:迭代闭环

这套策略不是一次写完的,而是靠一条纪律严格的循环持续进化:

1打牌线上实战或模拟对局,每次数千到数万手
→
2留痕每个决策记录:场景节点、胜率、过了哪条门槛
→
3找漏洞按场景聚合盈亏:哪个场景在持续漏钱?
→
4造靶验证构造针对性靶场对手,扫描参数找最优值
→
5回归门改动必须在标准模拟矩阵上不退化,才允许上线
↺

近期通过这条循环上线的改动(每一条都先在模拟里证明了自己):

3bet 池空气 c-bet:80%→30%(此前照搬单加注池频率,属于过度诈唬) 转牌/河牌连续开火砍频(×0.6 / ×0.3) 诈唬加注默认频率 10%→2%(实战数据:亏损全来自对粘人乱加注) 单加注池价值注放大 ×1.5
为什么不"看到哪亏就调哪"?扑克方差极大:一个场景几十手的盈亏几乎全是噪声。所以纪律是:live 数据只负责"提出嫌疑",定罪必须靠可控的模拟靶场(同样的牌、镜像座位、多随机种子);上线前还要过"标准对手矩阵不退化"这道门。上面每条改动都走完了全流程。

11. 它不做什么(诚实的局限)

  • 它不是 GTO。它压根不追求"不可被剥削"。比如"下大注 = 有真牌"这条范围假设,在 GTO 里是错的(均衡策略的大注掺满诈唬),但对普通玩家是对的。碰上会平衡诈唬的高手,这些假设会反过来被利用。
  • 成绩来自弱场。+1.5bb/手 是对线上匿名休闲对手池的战绩,不代表能赢职业桌。
  • 还有已知短板。翻后没有专门的 check-raise 线路(强牌只会平铺直叙地加注);河牌不做纯诈唬加注;试探性下注(float)残余小额亏损仍在优化队列里——这些都在遥测里明确记账,排队走第 10 节的流程。
  • 对手建模有滞后。档案要 18 手起判、场景门要 30 次观察起效,前几十手对新对手就是默认打法。

12. 术语小词典

术语意思
胜率 equity现在把牌发完摊牌,平均能赢下底池的比例。本文所有 0.xx 门槛都是它
范围 range某人此刻"可能拿着的所有手牌"的集合(或概率分布)
bb大盲注,筹码的通用计量单位。100bb = 100 个大盲
开池 / 3bet / 4bet本手第一个加注 / 对开池的再加注 / 对 3bet 的再加注
单加注池 / 3bet 池翻前只有一次加注 / 有过 3bet 的底池。3bet 池双方范围都强得多
c-bet持续下注:翻前的进攻方到翻后继续开火
半诈唬拿听牌下注:当下落后,但对手弃牌能赢、跟注也可能反超
float不是进攻方、也没牌,趁没人下注试探性偷池
SPR剩余筹码 ÷ 底池。SPR 低意味着"再打一两枪就全下了"
底池赔率跟注额 ÷(底池+跟注额)= 跟注保本所需的最低胜率
隐含赔率听中之后还能从对手那赢到的"未来钱",可以让当下略亏的跟注变划算
VPIP / PFR / AF松紧度 / 翻前主动性 / 翻后激进度,读人三件套(见第 8 节)
mbb/手千分之一大盲每手。+1503 mbb/手 ≈ 每手平均赢 1.5 个大盲
